| Zhang et al., "Multiple Doppler shifts compensation and ICI elimination by beamforming in high-mobility OFDM systems", ChinaCom 2011 | 狀態由專案負責人對話提供，Claude Code 未獨立確認（僅摘要） | 用陣列波束成形與干擾抑制補償高速 OFDM 中的多重都卜勒偏移、消除 ICI（依摘要層級的描述）。 | 本專案原有的 ICI 模型把 ICI 當功率項、接收端不做對頻；`ofdm_ici.js` 的最佳合併與 AD-MF 是同類想法的簡化實作，方法細節未與這篇比較。 |
| Gopala & Slock, "Doppler Compensation and Beamforming for High Mobility OFDM Transmissions in Multipath", EURECOM, 2016 | 狀態由專案負責人對話提供，Claude Code 未獨立確認（全文） | 對 SIMO OFDM 多路徑（各路徑有自己的都卜勒）建立含 ICI 的頻域模型，推導接收端最佳波束成形，並比較對頻選法與導頻估計的實務接收機（依對話中提供的公式與設定）。 | `ofdm_ici.js` 實作這些公式（編號 O1–O17），並加上獨立時域驗證、假設與敏感度、Estimated BF 損失的分解，以及只用導頻子載波訓練的協方差估計（等價於以導頻為樣本的協方差；與以同一批導頻為樣本的 R_yy 在 P_eff > Nr 時權重方向相同，P_eff = Nr 時不同；它不是修復方法本身，增益主要來自樣本來源，見 docs/ofdm_ici_assumptions.md A19）；原文的圖沒有逐圖比對。 |
| Guo et al., "High-Mobility OFDM Downlink Transmission with Large-Scale Antenna Array", IEEE Trans. Veh. Technol., 2017（arXiv 1701.03221；Wei Guo, Weile Zhang, Pengcheng Mu, Feifei Gao） | 狀態由專案負責人對話提供，Claude Code 未獨立確認（未提供） | 用波束成形網路在空間域分離多個載波頻偏，聯合估計都卜勒與振盪器頻偏，再對每個分支做單一頻偏補償與通道估計（依摘要）。 | 本專案的 AD-MF 是「每條路徑一個分支」想法的 genie 版（真實角度與都卜勒、不做估計）；該文有估計器，本專案沒有。 |
| Ge et al., "Beamforming Network Optimization for Reducing Channel Time Variation in High-Mobility Massive MIMO", arXiv 1809.00137（Yinghao Ge, Weile Zhang, Feifei Gao, Shun Zhang, Xiaoli Ma） | 狀態由專案負責人對話提供，Claude Code 未獨立確認（未提供） | 針對高鐵上行的快速時變通道，用大型均勻線性陣列的波束成形分離都卜勒，並以一個共同可調的振幅與相位參數最佳化波束成形網路，給出使都卜勒擴展最小的閉式解（依摘要）。 | 它設計降低通道時變的波束成形網路（摘要中為發射端、上行），本專案做的是接收端合併與協方差估計，沒有實作它的參數最佳化。 |
| Yan et al., "Doppler spread analysis for suppressing channel time variation in high-mobility massive MIMO V2V communications", IET Commun. 18(11), 2024 | 狀態由專案負責人對話提供，Claude Code 未獨立確認（未提供） | 依標題：分析高移動大規模 MIMO V2V 通訊中的都卜勒擴展，以抑制通道時變。 | 本專案是平坦頻率、直線軌道、單端移動的單一實現模型，沒有 V2V 的雙端移動，也沒有都卜勒擴展的解析分析；其餘內容未讀。 |
