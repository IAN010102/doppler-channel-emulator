# data/map_prototype.csv — 迷你限制因素地圖的資料（只有資料，沒有 UI；資訊性，不判定）

產生方式：`tests/map_prototype.js`（先用 `--part k/8` 分成 8 份各自計算，再用 `--merge` 合併成 `map_prototype.csv` 並寫出文字版熱圖 `docs/diagnostics/map_prototype_heatmap.txt`；8 個 CPU 約 2 分鐘）。種子 20160101，每格 200 次實現。

## 格點與設定

- 軸：車速 v ∈ {0, 50, …, 500} km/h（11 個）× 載波 fc ∈ {3.5, 7, 15, 28} GHz × 子載波間隔 Δf ∈ {15, 30, 60, 120} kHz（完整 16 個組合）× 陣列大小 Nr ∈ {2, 4, 8, 16}，共 704 格。
- 每格：SNR = 20 dB（`SNR = σx² Σ|A_i|²/σn²`，每天線、每子載波；假設 A1）、N = 1024、CP 7 %（Ncp = 72）、4 條路徑、相對強度 [0, 0, −11, −0.7] dB、隨機相位與隨機到達角 U(−90°, 90°)（A3、A4）、導頻間距 12。
- 路徑都卜勒 = f_m × [1, −1, 0.70, 0.20]，`f_m = v·fc/c`（假設 A6：把文獻設定的比例 [1080, −1080, 758, 220]/1080 縮放到各速度與載波）；`eps_max = f_m/Δf` 是最大的正規化都卜勒。
- 所有權重在同一個 CP 法（含雜訊樣本）估計的 ε̂ 下，與真實 H、R 比較。

## 欄位

| 欄位 | 定義 |
|---|---|
| `v_kmh, fc_GHz, df_kHz, Nr` | 格點座標 |
| `eps_max` | `f_m/Δf`（> 0.5 的格有 20 個；CP 法在 `|ε| < 0.5` 內才沒有相位模糊，這些格的 ε̂ 會被纏繞，結果要小心讀） |
| `L_ICI_db`、`L_ICI_se` | `10·log10(Nr·SNR / SINR_opt)`（SNR 為線性值 100，SINR_opt 取各實現 dB 值的平均）：最佳合併下仍存在的損失。**注意：v = 0 時它也不是 0**（Nr = 2：約 1.0 dB，Nr = 16：約 0.1 dB），因為 `Nr·SNR` 假設各路徑的通道增益 ‖H‖² 等於 Nr，而隨機角度與相位下路徑會互相疊加或抵消（衰落）。這一欄照規格定義，不扣基準 |
| `L_est_db`、`L_est_se` | `SINR_opt − SINR_pilot-residual`（導頻殘差協方差估計器：m = 1、γ_rel = +10 dB、Ĥ 由導頻估計、不修正）。γ_rel 固定在 +10 dB，不是最佳值（見 `data/pilot_residual_nr*.csv`：無加載或 Ledoit–Wolf 的損失更小） |
| `L_est_naive_db`、`L_est_naive_se` | `SINR_opt − SINR_estimated`，估計器為含訊號的樣本 R_yy（Ns = N）＋導頻 Ĥ |
| `ADMF_better_than_PR` | AD-MF（角度域匹配濾波，genie 基準：真實角度與都卜勒）的平均 SINR 高於導頻殘差法的平均 SINR |
| `dominant` | 「主導因素」＝ `L_ICI` 與 `L_est` 中較大者：`I` = ICI，`E` = 估計；兩者都小於 0.5 dB 時為 `-` |
| `L_ICI_net_db`、`dominant_net` | 額外欄位：`L_ICI` 扣掉同一個 Nr 在 v = 0 的值（只留都卜勒造成的部分，下限 0），以及用它判定的主導因素 |
| `L_aging_db` | **留空，待由窄頻模擬器結果匯入**（本表只有 OFDM 域的 ICI 與估計損失，沒有通道老化） |
| `n` | 每格的實現次數 |

## 限制（請在引用前讀）

1. 這是**模型內的原型資料**：路徑結構、都卜勒比例、隨機角度、平坦頻率通道、SNR = 20 dB 都是設定或假設，不是量測；沒有延遲擴散。
2. `L_ICI` 的 v = 0 基準（上表）會讓「ICI 主導」在低速格也被判成 `I`；`dominant_net` 與熱圖的 NET 版本扣掉了基準，較接近「都卜勒造成的 ICI」。兩種都列出，不下結論。
3. 「主導因素」只比較 `L_ICI` 與 `L_est` 兩項；沒有老化、沒有其他估計誤差（DoA、都卜勒估計）、沒有 AD-MF 以外的大陣列方法。
4. 導頻殘差法的 γ_rel = +10 dB 是固定的選擇，不是對每格最佳化的結果。
5. `eps_max > 0.5` 的 20 格：CP 法的 ε̂ 纏繞，「最佳」合併是在錯誤的對頻下，結果不代表可用的對頻估計器。
6. 同一格內各權重成對比較；格與格之間不成對。SE 只反映 200 次實現的抽樣不確定性，不含設定與假設的不確定性。

## 摘要（`docs/diagnostics/map_prototype_heatmap.txt` 有文字版熱圖，每個 Nr 兩張：照規格與 NET）

- 照規格定義：704 格中 ICI 主導 505、估計主導 0、兩者都 < 0.5 dB 有 199；扣掉 v = 0 基準後：ICI 主導 314、估計主導 0、兩者都 < 0.5 dB 有 390。
- 在這組設定下，導頻殘差法（γ_rel = +10 dB）的估計損失從不主導：`L_est` 的平均約 0.4–0.5 dB、最大 2.7 dB（Nr = 16，15 GHz，15 kHz，400 km/h）；含訊號的 `L_est_naive` 平均 3.1（Nr = 2）到 22.7 dB（Nr = 16）。
- `L_ICI` 最大 19.0 dB（Nr = 2，28 GHz，15 kHz，500 km/h）；ICI 損失隨 fc/Δf 增大而增大，隨 Nr 增大而減小。
- AD-MF（genie）只在 2 格優於導頻殘差法（Nr = 2，28 GHz，15 kHz，450 與 500 km/h，都在 `eps_max > 0.5` 的區域）。

## map_v2 (C3, branch array-map)

`map_v2.csv` — two slices of the limiting-factor map with an SNR axis (10 / 20 / 30 dB), generated by `tests/map_v2.js` (200 realisations per cell, 2112 cells).
Columns: `L_ICI_net_db` (Doppler-caused ICI loss, baseline at v = 0 subtracted, floored at 0), `L_ICI_raw_db`, `L_est_db` (clean estimator: pilot residual without loading), `L_est_naive_db` (signal in R_yy, all 1024 subcarriers), `dominant_clean` and `dominant_naive` (I = ICI, E = estimation, - = both below 0.5 dB), `excluded` (1 when eps_max = f_m / delta_f > 0.5, outside the CP-estimator range; left out of all proportions).
`map_v2_critical.csv` — critical Nr (for each SNR) and critical SNR (for each Nr) where L_est_naive = L_ICI_net (linear interpolation; empty = no sign change inside the grid). Informational.
Summary of the proportions: `docs/diagnostics/map_v2_summary.txt`.
